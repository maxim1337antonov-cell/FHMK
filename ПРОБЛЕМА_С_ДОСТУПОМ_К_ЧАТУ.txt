ПРОБЛЕМА С ДОСТУПОМ К ЧАТУ
============================================================

СИТУАЦИЯ:
---------
forwarder.py получает сообщения от @bmbsilaKR_bot ✅
НО не может переслать их в канал/группу ❌
Ошибка: "Peer id invalid: -1003281250682"

ВОЗМОЖНЫЕ ПРИЧИНЫ:
------------------
1. Аккаунт потерял доступ к каналу/группе
2. ID канала изменился
3. Что-то изменилось в Telegram API
4. Проблема с сессией Pyrogram

ЧТО ПРОВЕРИТЬ:
--------------
1. Откройте Telegram на том же аккаунте, от которого запущен forwarder.py
2. Проверьте, видите ли вы канал/группу с ID -1003281250682
3. Если не видите - добавьте аккаунт в канал/группу
4. Если видите - проверьте, что у аккаунта есть права на отправку сообщений

РЕШЕНИЕ:
--------
1. Добавьте ваш аккаунт в канал/группу (если его там нет)
2. Проверьте правильность ID канала (используйте get_chat_id.py)
3. Если у канала есть username - используйте его вместо ID
4. Перезапустите forwarder.py

ТЕКУЩИЙ СТАТУС:
---------------
✅ forwarder.py запущен
✅ Получает сообщения от @bmbsilaKR_bot
❌ НЕ МОЖЕТ отправить в канал/группу (ошибка "Peer id invalid")
