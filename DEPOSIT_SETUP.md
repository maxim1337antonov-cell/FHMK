# Настройка автоматического подтверждения депозитов

## Проблема
Уведомления от бота @bmbsilaKR_bot приходят только в самого бота, и наш бот не может их получить напрямую.

## Решение
Используется **мост (forwarder.py)** на базе Pyrogram, который:
1. Читает сообщения от @bmbsilaKR_bot
2. Пересылает их в канал/группу
3. Основной бот читает сообщения из этого канала/группы и автоматически подтверждает депозиты

## Настройка

### Шаг 1: Получите API credentials от Telegram
1. Зайдите на https://my.telegram.org/apps
2. Войдите со своим номером телефона
3. Создайте приложение (если еще не создано)
4. Скопируйте `api_id` и `api_hash`

### Шаг 2: Создайте канал или группу
1. Создайте приватный канал или группу в Telegram
2. Добавьте туда:
   - Ваш личный аккаунт (от которого будет запущен forwarder.py)
   - Основного бота (чтобы он мог читать сообщения)
3. Скопируйте ID канала/группы (можно узнать через @userinfobot или @getidsbot)

### Шаг 3: Настройте .env файл
Добавьте следующие переменные:

```env
# Для forwarder.py (мост)
TG_API_ID=ваш_api_id
TG_API_HASH=ваш_api_hash
TG_SESSION=forwarder_session  # Имя сессии (можно оставить по умолчанию)
SOURCE_BOT_USERNAME=bmbsilaKR_bot  # Username бота-источника
DEPOSIT_NOTIFY_CHAT_ID=-1001234567890  # ID вашего канала/группы (с минусом для каналов)

# Для основного бота (уже должно быть)
BOT_TOKEN=ваш_токен_основного_бота
```

### Шаг 4: Установите Pyrogram (если еще не установлен)
```bash
pip install pyrogram
```

### Шаг 5: Запустите мост
В отдельном терминале/процессе запустите:
```bash
python forwarder.py
```

При первом запуске вас попросят ввести номер телефона и код подтверждения.

### Шаг 6: Убедитесь, что основной бот запущен
Основной бот должен быть запущен и иметь доступ к каналу/группе, указанному в `DEPOSIT_NOTIFY_CHAT_ID`.

## Как это работает

1. **@bmbsilaKR_bot** отправляет уведомление в личные сообщения:
   ```
   Сумма 0.00007839 BTC (650 RUB)
   
   Была зачислена на ваш счет.
   
   🤵🏼От: @K0_T_1K
   ```

2. **forwarder.py** (мост) перехватывает это сообщение и пересылает его в канал/группу

3. **Основной бот** читает сообщение из канала/группы, парсит сумму и username, находит сделку и автоматически подтверждает депозит

4. **Пользователь** получает уведомление о подтверждении депозита

## Проверка работы

1. Убедитесь, что `forwarder.py` запущен и показывает "✅ Мостик готов к работе!"
2. Отправьте тестовое сообщение от @bmbsilaKR_bot
3. Проверьте, что сообщение появилось в канале/группе
4. Проверьте логи основного бота - должно появиться сообщение о подтверждении депозита

## Альтернативный вариант (без forwarder.py)

Если вы не хотите использовать Pyrogram, можно:
1. Настроить @bmbsilaKR_bot на пересылку уведомлений в канал/группу (если у вас есть доступ к настройкам бота)
2. Или использовать бота с токеном DEPOSIT_BOT_TOKEN для пересылки (но это сложнее)

## Важно

- `forwarder.py` должен работать постоянно (как и основной бот)
- Убедитесь, что ваш личный аккаунт добавлен в канал/группу
- Убедитесь, что основной бот добавлен в канал/группу и имеет права на чтение сообщений
